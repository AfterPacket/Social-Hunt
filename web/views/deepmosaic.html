Tips

  • Clean mode — works best on faces in well-lit, clear images.
  • Add mode — useful for anonymising before sharing screenshots or video.
  • Style mode — artistic filter; results vary by model.
  • Video — processing time depends on length and quality setting. Long videos can take several minutes.
  • No models? Run the download script or grab them from the DeepMosaics Google Drive link in the README.
